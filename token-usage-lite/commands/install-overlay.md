---
帮助用户手动把悬浮 token 用量状态条安装到本机 ZCode 桌面客户端(自动安装失败时的兜底)。

执行:用 Bash 运行安装器(插件根目录 = 本命令文件所在目录的上一级):

    python3 "<插件根目录>/vendor/zusage/overlay_install.py" install

结果处理(按以下优先级,不能仅凭退出码 0 判断无需重启):

- 失败、待收尾或输出不确定:优先转述实际输出,不得宣称安装成功。
- 输出"已安装/已更新,请完全退出 ZCode 重开"类提醒:在回复第一行用引用块原样加粗转述该提醒(状态条加载后会以红色显示),并提醒用户:从 ZCode 菜单「退出」后重开,只关窗口/重开会话无效。
- 仅输出"已安装,注入行已指向当前目录"且无待重启提醒:回复无需操作。
- 权限不足(Linux 系统位置)时按安装器提示处理;输出"运行中替换失败/待收尾"时,请用户完全退出 ZCode 后重跑本命令。

补充:卸载用 `/uninstall-overlay`;自动安装始终开启(会话启动时),只有卸载豁免能阻止。

用户附加要求:$ARGUMENTS
